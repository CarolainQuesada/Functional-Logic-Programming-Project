Detailed Description

Project documentation

This directory contains the input contract, model/parser/validation/generation explanations, pipeline architecture, execution evidence, requirements checklist, and defense guide.

Run python tools/build_docs.py from the repository root. It extracts source declarations into docs/api/ and builds Doxygen HTML at docs/html/index.html using docs/Doxyfile. Both generated directories are committed to the repository so teammates can browse them without rebuilding, and both are included in the submission archive.

Start with architecture.md, verification.md, requirements-checklist.md, and defense-guide.md. team-handoff.md records completed work and remaining team actions.
