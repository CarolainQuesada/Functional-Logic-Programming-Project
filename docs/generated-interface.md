# Generated interface

`Html.renderHtml` validates the supplied model and builds a complete Spanish HTML document. Tables use parsed records and physical line numbers; knowledge and query blocks use the same `Prolog.generateProlog` function as the downloadable files. No sample names or facts are embedded in the template.

The page includes entity declarations, relations, requested rules, generated facts and rule definitions, suggested queries, diagnostic source locations, and related declaration lines. Invalid input suppresses executable knowledge and its download links while keeping diagnostics visible. Warning-only input remains usable.

`HtmlStyle.stylesheet` supplies self-contained responsive CSS. The page has semantic sections, table captions and column headers, keyboard focus states, a skip link, and reduced-motion support. It requires no scripts, third-party assets, or network connection.

All input-derived text is escaped for HTML. The 19 HTML checks cover required content, source traceability, regeneration with alternate names, valid/warning/error/empty states, escaping, responsive styles, and offline behavior. Browser checks are recorded in [verification evidence](verification.md).

## Visual design

The interface uses a warm ivory notebook palette, terracotta and sage accents, serif headings, numbered workspace sections, and dark Prolog code panels with distinct comments. The connection atlas is an inline SVG generated from the actual entity declarations and relation references. People and teachers appear on the left, courses on the right; edges follow input relations. Empty input has an explicit atlas placeholder. The atlas has an accessible image label, node titles, and an internally scrollable viewport for larger datasets. No graph data is hardcoded.

The page was visually reviewed at desktop and mobile sizes after the redesign. Primary, alternate, assignment, Unicode, and invalid scenarios pass the browser checks.

Visible navigation, headings, table labels, states, accessibility labels, and diagnostic explanations use Spanish. Prolog predicates, diagnostic codes, source excerpts, input names, and required filenames retain their original technical spelling.
