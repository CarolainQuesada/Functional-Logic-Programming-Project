# Generated interface

`Html.renderHtml` validates the supplied model and builds a complete English HTML document. Tables use parsed records and physical line numbers; knowledge and query blocks use the same `Prolog.generateProlog` function as the downloadable files. No sample names or facts are embedded in the template.

The page includes entity declarations, relations, requested rules, generated facts and rule definitions, suggested queries, diagnostic source locations, and related declaration lines. Invalid input suppresses executable knowledge and its download links while keeping diagnostics visible. Warning-only input remains usable.

`HtmlStyle.stylesheet` supplies self-contained responsive CSS. The page has semantic sections, table captions and column headers, keyboard focus states, a skip link, and reduced-motion support. It requires no scripts, third-party assets, or network connection.

All input-derived text is escaped for HTML. The 18 HTML checks cover required content, source traceability, regeneration with alternate names, valid/warning/error/empty states, escaping, responsive styles, and offline behavior. Actual browser checks are recorded in the final verification evidence after integration.
