# Generated output

This directory is reserved for files generated by the Haskell pipeline:

- `conocimiento.pl`: Prolog facts and rules.
- `consultas.pl`: suggested Prolog queries.
- `index.html`: generated web interface.
- `reporte_validacion.txt`: validation errors and warnings.

Preserve assignment-required filenames. Generated files must be recreated from the input rather than maintained manually. Only this README is tracked by Git; generated files and subdirectories are ignored.

Stage 6 produces the report and both Prolog files with `runghc -Wall -Werror -isrc app/GenerateProlog.hs` from the repository root. HTML generation is not implemented yet.
