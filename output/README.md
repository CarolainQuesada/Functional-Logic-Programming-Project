# Generated output

This directory is reserved for files generated by the Haskell pipeline:

- `conocimiento.pl`: Prolog facts and rules.
- `consultas.pl`: suggested Prolog queries.
- `index.html`: generated web interface.
- `reporte_validacion.txt`: validation errors and warnings.

Preserve assignment-required filenames. Generated files must be recreated from the input rather than maintained manually. Primary outputs, demonstration examples, browser evidence, and the submission ZIP are tracked so teammates can download them from develop. Temporary test output remains ignored.

Run `runghc -Wall -Werror -isrc app/Main.hs` from the repository root to regenerate all four artifacts. Invalid input updates the HTML/report and replaces Prolog with blocked comment markers. Do not edit generated files manually.

Browser evidence is stored in `browser-checks/`, `browser-alternate/`, and `browser-invalid/`. Automated scenarios live in `prolog-checks/` and `pipeline-checks/`. `submission.zip` is the generated deliverable archive.
